If interviewer asks: Access Token vs Refresh Token? 🤔
Explain with example 👇

You login to app → Auth Server gives you 2 tokens:

🔑 Access Token = Temporary Digital Pass (15 mins)
→ Used to access protected APIs (profile, orders)
→ Expires fast = 401 Unauthorized

♻️ Refresh Token = Long-lived (30 days)
→ Job is to get a NEW Access Token
→ Happens in background, no login needed

Security? Access Token = short-lived, limited misuse
Refresh Token = stored securely, can be rotated/revoked

Simple difference:
Access Token → Access APIs
Refresh Token → Get new Access Token
